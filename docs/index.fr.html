Crade Cortex

Un Pico envoie du MIDI, un Raspberry Pi renvoie son état sur le même câble. Les LED n'affichent pas ce que le pied a demandé — elles affichent ce que le Pi a confirmé.

Pico RP2040 · CircuitPython · LCD1602 — Raspberry Pi · PiPedal 2.0.110
English  ·  Protocole websocket  ·  Câblage  ·  Dépôt

Section 1Vue d'ensemble

PiPedal est la seule source de vérité. Le Pico n'a pas d'état propre. Il envoie un CC et attend. La LED ne s'allume que sur confirmation.

Section 2Matériel

Le pédalier repose sur un Raspberry Pi Pico, huit footswitches, huit LED et un LCD1602. Le détail du câblage est dans CABLAGE.md.

Section 3Switches

Les quatre switches avant envoient les snapshots, les quatre arrière servent aux commandes de navigation et à l'accordeur. Voir la documentation de câblage pour les GPIO et CC exacts.

Section 4Le Pico

Quatre fichiers à la racine du lecteur CIRCUITPY, plus une bibliothèque.

Prérequis. Le dossier adafruit_character_lcd/ doit être dans /lib, depuis le bundle CircuitPython officiel. Sans lui, import ecran lève une exception et le pédalier ne démarre pas du tout.

boot.py

usb_midi.enable()
usb_cdc.enable(console=True, data=True)
supervisor.set_usb_identification(product="Pedalier")
usb_midi.set_names(streaming_interface_name="Switches")

Budget endpoints du RP2040 : 7 paires utilisables. CIRCUITPY (1) + console (2) + data (2) + MIDI (1) = 6, une paire de marge. En cas de mode sans échec, passer console=False.

Hard reset obligatoire. boot.py n'est relu qu'à la mise sous tension. Enregistrer le fichier ne suffit pas. Ses print() vont dans boot_out.txt, jamais sur la console.

Les quatre modules

FichierRôle
boot.pyIdentification USB, activation du port data
code.pyScrutation antirebond, MIDI, LED, boucle principale
ecran.pyPilote LCD, translittération, cache par ligne, animations
retour_pipedal.pyProtocole série bidirectionnel
retour.init(allumer_exclusif, NB_SNAPSHOTS, ecran, callback_led=led)
retour.appui(i)                  # switch snapshot
retour.attente_changement(i)     # switch preset
retour.tick()                    # dans la boucle

Section 5Affichage

Démarrage

+----------------+ | CRADE CORTEX | |########## | +----------------+

Les lettres apparaissent une par une, à leur place définitive.

Normal

+----------------+ |Fender Clean | |2 Chorus | +----------------+

Ligne 1 : nom du pedalboard sur 15 caractères, plus un indicateur de lien en colonne 16. Ligne 2 : numéro et nom du snapshot actif.

Accordeur

+----------------+ | E2 -12c | |.......|#|......| +----------------+

Le marqueur # se déplace, le repère central occupe les colonnes 7 et 8.

Section 6Protocole série

Une ligne ASCII par événement, terminée par \n. Bidirectionnel.

Pi → Pico

TrameSignification
S<n>Snapshot n actif — base 1
HBBattement de cœur, 1 Hz
N:<texte>Nom du pedalboard
M:<texte>Nom du snapshot actif
T:<note>:<cents>Accordeur
T:-Accordeur, aucun signal
T:!Aucun accordeur dans le pedalboard

Pico → Pi

TrameSignification
A1 / A0Entrée / sortie du mode accordeur
?Demande de l'état complet, au démarrage

Section 7Resynchronisation

Le Pico et le démon se resynchronisent après redémarrage ou perte du port série.

Section 8Le Pi

Le démon

sudo apt install python3-serial
pip3 install websockets --break-system-packages
python3 pipedal_bridge.py -v

Il s'abonne au websocket en localhost, met l'état en cache et n'émet que sur changement. Reconnexion avec backoff exponentiel, et disparition du port série sans plantage.

Règle udev

Sans elle, le numéro de ttyACM peut changer selon l'ordre de branchement des périphériques USB.

# /etc/udev/rules.d/99-pipedal-pico.rules
SUBSYSTEM=="tty", ATTRS{idVendor}=="239a", ATTRS{product}=="Pedalier", \
  ENV{ID_USB_INTERFACE_NUM}=="02", SYMLINK+="pipedal-pico"
sudo udevadm control --reload && sudo udevadm trigger
ls -l /dev/pipedal-pico

L'interface 02 est le port data. La console porte un autre numéro.

Service systemd

# /etc/systemd/system/pipedal-bridge.service
[Unit]
Description=Pont PiPedal vers pedalier Pico
After=pipedald.service
Wants=pipedald.service

[Service]
Type=simple
User=pi
WorkingDirectory=/opt/crade-cortex
ExecStart=/opt/crade-cortex/.venv/bin/python3 /opt/crade-cortex/pipedal_bridge.py
Restart=always
RestartSec=2

[Install]
WantedBy=multi-user.target
